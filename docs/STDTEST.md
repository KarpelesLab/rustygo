# The standard library's own tests

Each package's test binary is the one `go list -test` writes — the main that
registers every `TestXxx` and calls `testing.Main` — built with rustygo and run
with `-test.v`. The counts are of the tests the package ships, not of tests
written here.

Two kinds of failure are counted apart from the rest, because neither is news
about the package. A test that fails under gc on this machine as well is the
machine's news: this one's Go has no `regexp/testdata`, and two of
`regexp`'s tests want it. And a test that counts allocations is waiting on
escape analysis (M6): a local variable whose address is taken is a heap object
here and is not under gc. Those are listed by name rather than counted as
failures, because some of them already pass — `bytes.Equal` is written
`string(a) == string(b)`, and that comparison no longer copies either side.
